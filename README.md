# Para o meu Noah ❤️

Site-surpresa da Raissa para o Noah.

## Publicação

A carta e a página já estão neste repositório. Para instalar as imagens e o violão:

1. Baixe o arquivo `Carta_para_Noah_site_completo.zip` entregue na conversa do ChatGPT.
2. Em [Upload files](https://github.com/Cubacreator/para-o-meu-noah/upload/main), envie **o arquivo ZIP inteiro** (sem extrair), com o nome exato `Carta_para_Noah_site_completo.zip`, na raiz do repositório.
3. Confirme a mudança em **Commit changes**.
4. A ação [Instalar fotos e música](https://github.com/Cubacreator/para-o-meu-noah/actions/workflows/instalar-midias.yml) extrairá a pasta `assets/` automaticamente.
5. Em [Settings > Pages](https://github.com/Cubacreator/para-o-meu-noah/settings/pages), escolha **Deploy from a branch**, **main**, **/(root)** e **Save**.
6. Quando publicar, o endereço será `https://cubacreator.github.io/para-o-meu-noah/`.

**Atenção:** o repositório é público. As fotos e a carta ficarão acessíveis a qualquer pessoa que obtiver o endereço.
